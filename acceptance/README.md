# 受け入れテスト

**この仕組みを作っていない環境で、ドキュメントだけを見て動かせるか**を確かめる記録の置き場。

- `prompts.md` — 各マシンに渡すプロンプト（そのまま貼る）
- `<マシン名>.md` — 実施した人（AI）が書く記録

## 読む人へ

テストされているのは**あなたではなく、ドキュメントと仕組み**です。
詰まったら、詰まったまま書いてください。推測で乗り切ると、直すべき場所が分からなくなります。

**「動きました」だけの報告は受け取れません。** 検査が動いていることは、
**仕込みで落ちること**でしか確かめられません。通ることの確認だけでは、
何も見ていない可能性を排除できません。

## なぜこの形か

qnd-database（2026-08-28）で、「作ったのに動いていない検査」を6回踏みました。
症状はすべて **「緑なのに何も検査していない」**。そのうち3件は、
**書いた本人には見えず、別のマシンのメンバーが手を動かして初めて分かりました。**

| 見つかったもの | 誰が |
|---|---|
| 日本語の文字列で成否を判定していて、cp932 環境では違反0でも失敗 | Windows |
| 対象を `git ls-files` で集めており、新規作成ファイルを検査しない | Mac mini |
| 絶対パスを渡しており、Git Bash の `/c/...` を Windows の Python が解決できず**97ファイル全部が素通り**。それでも「OK」と表示 | Windows |

この記録は、その再発を防ぐためのものです。
